# 按工种委派与成果回传

角色由交付物决定，不建立固定虚拟团队。例如展览任务可拆为内容研究、空间视觉与交付成本；软件任务可拆为接口、界面与校验；影视任务可拆为剧本、分镜与资产。按需使用相关 skill，不将所有专业手册载入主对话。

## 任务契约

每个 worker 收到以下最少信息，可落盘至 `.project-memory/tasks/<task-id>/brief.md`：

```text
目标/工种：
验收条件：
已确认约束及来源：
输入绝对路径及需读取的范围：
独占写入目录/文件：
共享接口及前置依赖：
允许工具、外部处理范围及本任务预算：
输出：成果路径 + report.md；最终回传 <=500 汉字
禁止修改：规范记忆、其他 worker 文件；不得自行扩展任务或委派
```

独立任务并行；依赖任务先确定接口或顺序执行。遵守宿主并发上限。共享文件系统下分配独占写域或 worktree，主 agent 顺序集成。优先无历史继承；worker 从指定路径自行取证，不要求父 agent 粘贴大量资料。不支持隔离时说明实际行为。

用户新约束到达时及时转发给相关 worker，取消失效工作，保留旧产物与被替代状态。超出预算、缺权限或工具失败时如实返回，不自主循环重试。

涉及可变要求时按 [反馈与修订协议](feedback-revisions.md) 使用task-pin固定来源，简报/回传附任务ID及修订号。集成前执行task-check；新要求导致旧任务失效时使用新ID固定新修订，不接受迟到的旧成果。

## 回传格式

```text
状态：完成/部分完成/阻塞/取消
成果：绝对路径（图片另需可展示产物）
验证：实际操作和结果；未验证范围
阻碍/需要主 agent 决定：
详细报告：绝对路径
记忆候选：如有，附来源与状态
```

不回传长日志、完整资料、全部候选图或提示词；不能为了简短隐瞒缺陷。主 agent 检查真实文件、接口与验收证据，有矛盾再打开报告相关部分。

宿主支持时关闭完成的临时 worker；关闭不抹除回传上下文，也不删除成果。无关闭工具时停止给它新工作。主 agent 维护规范记忆，worker 只写独占任务目录。主对话简述角色和成果，不逐条播报内部消息。

能力参考（2026-11-05核对）：[官方 Subagents 文档](https://learn.chatgpt.com/docs/agent-configuration/subagents)、[官方 Build skills 文档](https://learn.chatgpt.com/docs/build-skills)。实际可用工具与当前宿主约束优先，不将 API 功能假定为桌面端已开放功能。
