# 临时生图 worker

目的：提示词迭代、参考读取和生成过程尽量留在独立执行上下文，主对话接收最终图片、最少状态和成果路径。

1. 检查原生 worker、图片工具及参考路径是否可用，工具是否支持跨 agent 返回图片。工具列表可见不等于已调用成功。遵循实际 imagegen 或相关生图 skill 的必要流程。
2. 主 agent 明确画面用途、尺寸/透明度、风格锚点、必须保留项、验收条件与已授权的生成范围。使用 worker 能取得的路径或附件机制，不能假定它能看到父对话附件。
3. 分配 `.project-memory/tasks/<id>/`，优先无历史继承；只给简报与参考路径。不要覆盖原图。
4. 默认完成用户要求的一轮；额外变体和重试遵循用户数量、成本和工具要求。没有迭代额度时，不开展自主多轮探索。失败或不符要求如实返回。
5. 工具支持时将最终图片持久保存到任务目录 artifacts；提示词、参考清单、实际参数、可见工具返回和验收结果写报告。不伪造种子、模型或下载成功。无法保存时保留实际可用产物链接并注明可能过期；不为绕过呈现限制下载远程媒体。
6. worker 返回最终图片的原生产物或真实绝对路径及短状态，不返回 Base64、全量提示词或中间图。主 agent 只查看验收所需最终图，并用原生产物或 `![说明](绝对路径)` 展示；路径无效时不能宣称交付。

本地保留可见过程，主对话保留结果与最少状态。宿主可能注入工具摘要或 worker 最终消息，不能保证主上下文严格只有图片，不能承诺隐藏 UI 记录或删除历史。

图片不能跨 agent 返回或工具仅主 agent 可用时：worker 仅整理素材/提示词落盘，主 agent 调用生成工具。明确这是降级路径，生成过程可能进入主上下文。不为隔离效果重建昂贵服务或未经授权上传素材；外部处理遵循当前用户及项目限制。
