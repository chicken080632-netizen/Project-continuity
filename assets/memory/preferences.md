# 项目执行偏好

以下为建议默认值，不代表用户已逐项确认；用户确认时记录原话、来源和适用范围。

- 协作：按交付物选择工种，在用户/适用 skill 授权和宿主允许范围内，独立任务可委派；小且紧耦合的工作单 agent 完成。初始化不授予未来所有任务的永久协作权限。
- 上下文：worker 最少背景，详细报告落盘，最终建议不超过500汉字；图片优先临时 worker，仅回传成果和必要状态，能力不足如实降级。
- 记忆：关键要求和纠正及时记录，阶段结束更新检查点；原文按批归档、注明来源与缺口，按需检索；不自动删除旧档。
- 维护：主 agent 维护规范记忆，worker 只写独占任务目录。
- 来源：区分用户确认、工具证据、agent 建议和未验证假设。
- 隐私：不保存凭据，外部处理沿用项目授权，迁移前检查敏感内容。

- 特征优先：按语义片段建立关键词/别名/实体/情境卡，先 recall 唤回原文，再按需读取事件记录；不要求先有完整目标或结果才能记忆。
